Gudang Referensi Gaya Edit

Unggah video referensi agar AI mengekstrak gaya visual, warna, zoom & B-roll secara otomatis, atau pilih template bawaan.

Pengaturan Studio

Konfigurasi endpoint Backend API, Pixabay B-Roll API Key, standar ekspor video, dan bahasa subtitle otomatis ClipA Studio.

URL YouTube dikirim ke endpoint ini terlebih dahulu. Jika backend mengembalikan URL stream .mp4, klip dapat langsung dipotong dan diunduh di browser.
Mode Cadangan Otomatis
Disimpan lokal di browser. Jika diisi atau tersedia di server (PIXABAY_API_KEY), B-Roll otomatis menarik video MP4 & foto stok HD dari Pixabay; jika kosong, otomatis menggunakan media cadangan bebas hak cipta.
Unggah Video Referensi Gaya
AI mengambil 3 frame kunci (20%, 50%, 80% durasi) secara lokal lalu mengekstrak gaya subtitle, warna sorotan, ritme zoom, & aturan B-roll.
